# Smart Campus Information System

A comprehensive Python-based terminal application for managing student records, course enrollments, fee calculations, file handling, directory scanning, and performance analytics.

Built as a multi-module academic lab project demonstrating core Python programming concepts including:

- Functions
- Lists, Dictionaries, and Sets
- File Handling
- Exception Handling
- Sorting & Searching Algorithms
- Data Analytics using NumPy, Pandas, and Matplotlib

---

## Features

### Module 1 — Student Registration & Grade Evaluation
- Register students
- Assign grades automatically based on score
- Generate student reports
- Auto-generate student IDs

### Module 2 — Course Enrollment Management
- Enroll students into courses
- Credit management
- Maximum course limit validation
- View enrollment reports

### Module 3 — Student Record Management
- Store and update grades
- Average grade calculation
- Event participation analysis using Set operations:
  - Union
  - Intersection
  - Difference

### Module 4 — Sorting & Searching Student IDs
Implements classic algorithms manually:
- Bubble Sort
- Selection Sort
- Linear Search
- Binary Search

### Module 5 — Fee Calculation
- Tuition fee calculation
- Hostel fee support
- Transportation fee support
- Fee summary reports

### Module 6 — File-Based Academic Record Management
- Write student records to file
- Read records from file
- Generate file-based reports

### Module 7 — Directory Scanning & Exception Handling
- Recursive directory scanning
- Empty folder detection
- Custom exception handling
- Sample project directory generation

### Module 8 — Performance Analytics
Uses:
- NumPy
- Pandas
- Matplotlib

Capabilities:
- CSV dataset generation
- Statistical summaries
- Top performer analysis
- Performance visualization charts
